# Padho AI — Learning Gap Detective

Next.js starter website for Class 8 Mathematics: Fractions.

## Run locally
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Deploy
Push this folder to a GitHub repository, then import that repository from the Vercel dashboard and deploy.

## Included
- Responsive homepage and navigation
- Four written lessons
- Five-question diagnostic quiz with score and explanations
- English/Telugu selector for main navigation and homepage copy
- Lesson completion and progress saved in browser local storage

## Not yet connected
AI API, cloud database/accounts, verified video catalogue, and full Telugu translations. Do not present those features as live until configured and tested.
